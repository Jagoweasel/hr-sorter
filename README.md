# HR Sorter

Единый пульт управления для работы с рекрутерами в Telegram и HeadHunter. Позволяет агрегировать переписки, управлять воронкой найма и генерировать отчеты.

## 🚀 Возможности
- **Мультиаккаунтность**: Поддержка нескольких аккаунтов Telegram (через Userbot API) и HeadHunter (через эмуляцию мобильного приложения).
- **Синхронизация**: Автоматический сбор контактов и истории сообщений в реальном времени.
- **Pipeline (Канбан-доска)**: Управление кандидатами по стадиям (Отклик, Интервью, Оффер и др.).
- **Умный Mapping**: Автоматическая привязка чатов к конкретным вакансиям на основе регулярных выражений.
- **Отчетность**: Генерация PDF-отчетов и экспорт данных в Excel.
- **Современный Web UI**: Быстрый интерфейс на Go Templates + HTMX + Tailwind CSS (с поддержкой темной темы).

## 🛠 Установка и запуск

### Вариант 1: Docker (Рекомендуется)
Самый простой способ, не требующий установки Go и зависимостей Playwright на хост-машину.

1. Скопируйте `.env.example` в `.env` и настройте параметры:
   ```bash
   cp .env.example .env
   ```
2. Запустите контейнеры:
   ```bash
   docker compose up --build
   ```
3. Откройте `http://localhost:3000`.

### Вариант 2: Нативный запуск (Go)
Требуется **Go 1.25+**.

1. **Установите зависимости и браузеры Playwright**:
   ```bash
   go mod download
   go run github.com/playwright-community/playwright-go/cmd/playwright install --with-deps
   ```
2. **Настройте окружение** в файле `.env`.
3. **Запустите приложение**:
   ```bash
   go run ./cmd/hrsorter/main.go
   ```

## ⚙️ Конфигурация (.env)
- `HTTP_PORT`: Порт веб-интерфейса (по умолчанию 3000).
- `DB_PATH`: Путь к файлу SQLite (по умолчанию `data/hr-sorter.db`).
- `HEADLESS`: `true` для запуска браузера HH в фоновом режиме (рекомендуется для сервера).
- `CSRF_SECRET`: Секретная строка (32 символа) для защиты форм.

*Примечание: API_ID и API_HASH для Telegram теперь настраиваются индивидуально для каждого аккаунта через Web UI.*

## 📖 Как пользоваться

1. **Добавление аккаунта**: Перейдите в раздел "Accounts" и создайте новый аккаунт (логическое объединение ваших интеграций).
2. **Подключение Telegram**: Внутри аккаунта добавьте интеграцию TG. Введите номер телефона, затем код из Telegram (и пароль 2FA, если есть) прямо в веб-интерфейсе.
3. **Подключение HeadHunter**: Добавьте интеграцию HH. Введите email/телефон, дождитесь открытия окна авторизации (если `HEADLESS=false`) или введите код подтверждения в UI.
4. **Настройка маппинга**: В разделе "Vacancy Mapping" создайте правила. Например: паттерн `Go Developer` будет автоматически помечать соответствующие чаты.
5. **Pipeline**: Перетаскивайте карточки кандидатов между колонками для отслеживания прогресса.

## 🐞 Отладка
При запуске можно использовать флаги для расширенного логирования:
- `--debug-tg`: Логи взаимодействия с Telegram.
- `--debug-hh`: Логи HeadHunter (авторизация, запросы).
- `--debug-filters`: Логи работы фильтров сообщений.
- `--debug-all`: Включить все возможные логи.

Все логи также доступны в реальном времени в разделе **System Logs** веб-интерфейса.

## 🏗 Технологический стек
- **Backend**: Go 1.25, `gotd` (Telegram), `playwright-go` (HeadHunter).
- **Frontend**: HTMX, Tailwind CSS, Alpine.js (через скрипты).
- **Database**: SQLite (WAL mode).
- **Reports**: Maroto (PDF), Excelize (Excel).
