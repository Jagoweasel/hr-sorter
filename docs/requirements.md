# Требования к Alpha-версии (Локальный запуск через Docker)

## 1. Обзор
Цель задачи — обеспечить возможность развертывания приложения `hr-sorter` одной командой `docker-compose up --build` без необходимости предварительной настройки окружения (Go, Playwright, SQLite) на хост-машине. Весь процесс должен быть максимально автоматизирован для конечного пользователя.

## 2. Технический стек и Инфраструктура
- **Язык**: Go 1.25+
- **База данных**: SQLite 3 (Modernc Pure Go driver)
- **Браузер**: Playwright (Chromium) — обязателен для авторизации HH.
- **Окружение**: Docker + Docker Compose.
- **Базовый образ**: `debian:bullseye-slim` (выбран из-за стабильной поддержки системных библиотек Playwright).
- **Порт**: Приложение должно быть доступно по адресу `http://localhost:3000`.
- **Ветки**: Все изменения для реализации этой задачи должны быть зафиксированы в ветке `docker-build`.

## 3. Функциональные требования

### 3.1 Хранение данных (Persistence)
- Файл базы данных и файлы сессий должны сохраняться в локальной директории `./data` на хосте.
- В контейнере путь к данным: `/app/data/`.
- В `.env` по умолчанию: `DB_PATH=/app/data/hr-sorter.db`.

### 3.2 Управление портами
- Стандартный порт для доступа к Web UI: **3000**.
- Приложение должно считывать порт из переменной окружения `HTTP_PORT`.

### 3.3 Автоматизация запуска
- Приложение должно автоматически создавать необходимые директории (например, `/app/data`), если они отсутствуют, во избежание ошибок при первом запуске.

## 4. Технические задачи

### 4.1 Исправления в Dockerfile
- Исправить путь к `main.go` для команды сборки: `go build -o hr-sorter ./cmd/hrsorter/main.go`.
- Обеспечить создание папки `/app/data` внутри образа.
- Оптимизировать процесс установки браузеров Playwright: `playwright install chromium --with-deps`.

### 4.2 Исправления в Docker Compose
- Настроить маппинг портов: `3000:3000`.
- Оставить только необходимые volume: `./data:/app/data`.
- Удалить лишние маппинги (например, проброс всего корня проекта).

### 4.3 Доработки кода (Golang)
- В `cmd/hrsorter/main.go` изменить значение порта по умолчанию на `3000`.
- В `cmd/hrsorter/main.go` (перед инициализацией БД) добавить вызов `os.MkdirAll` для пути из `DB_PATH`, чтобы гарантировать наличие папки для SQLite.

## 5. Документация
- Обновить `README.md`, добавив раздел "Быстрый старт через Docker".
- Привести пример минимального `.env` файла.

## 6. Критерии приемки
1. Приложение успешно собирается командой `docker-compose up --build`.
2. Веб-интерфейс открывается по адресу `http://localhost:3000`.
3. После перезапуска контейнера (`down` -> `up`) данные (аккаунты, сообщения) сохраняются.
4. Логи приложения (включая логи Playwright) доступны через стандартный вывод Docker.
5. Код и конфигурации находятся в ветке `docker-build`.
